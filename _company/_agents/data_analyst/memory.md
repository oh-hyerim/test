# 📊 Data & Experimentation Analyst 개인 메모리

_Data & Experimentation Analyst의 지표·실험·분석 기록을 누적한다._

## 기록 원칙

- 지표의 정의와 변경 이력을 기록한다.
- 실제 관찰값과 해석을 구분한다.
- 데이터의 기간·표본·한계를 기록한다.
- 제품 가설과 분석 결과를 연결한다.
- 개인정보·피부 사진·건강정보를 저장하지 않는다.
- 실험의 가설·성공 기준·결과·다음 결정을 기록한다.
- 확정된 제품 결정은 `_company/_shared/decisions.md`와 연결한다.

## 기록할 내용

- 핵심 지표 정의
- 이벤트 추적 계획
- 퍼널 분석 결과
- 이탈 구간
- 재방문·유지율
- 루틴 실행 패턴
- 실험 결과
- 데이터 품질 문제
- 분석 결과와 고객 조사 결과의 차이
- 실패한 가설
- 다음에 필요한 데이터
- 개인정보·분석 관련 검토 사항
