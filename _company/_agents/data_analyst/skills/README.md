# 📊 Data & Experimentation Analyst 스킬

_제품 데이터 분석과 실험에서 검증된 방법과 반복 가능한 분석 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 실제 제품 데이터와 실험에서 검증된 지표 정의·분석 방법·해석 기준을 저장한다.

## 스킬 추가 원칙

- 실제 데이터나 실험에서 검증된 방법만 추가한다.
- 지표 정의와 적용 조건을 함께 기록한다.
- 작은 표본이나 특정 사용자군에만 적용되는 방법은 범위를 표시한다.
- 상관관계와 인과관계를 구분한다.
- 개인정보를 분석 스킬에 저장하지 않는다.
- 오래된 분석 방식은 현재 제품과 데이터 구조에 맞는지 다시 확인한다.

## 나중에 추가할 스킬 예시

- `event_tracking.md`
- `funnel_analysis.md`
- `retention_analysis.md`
- `experiment_design.md`
