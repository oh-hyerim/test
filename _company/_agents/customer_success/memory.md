# 🤝 Customer Success 개인 메모리

_Customer Success 에이전트의 사용자 지원·문의·피드백·이탈 관련 기록을 누적한다._

## 기록 원칙

- 사용자 이름 대신 익명 ID와 문의 ID를 사용한다.
- 사용자의 원문·관찰된 행동·조사자의 해석을 구분한다.
- 문의가 실제로 처리되었는지 상태를 기록한다.
- 해결되지 않은 문제를 해결 완료로 기록하지 않는다.
- 개인정보·피부 사진·건강정보를 불필요하게 저장하지 않는다.
- 반복되는 문제와 단발성 의견을 구분한다.
- 중요한 제품 결정은 `_company/_shared/decisions.md`와 연결한다.

## 기록할 내용

- 반복 문의
- 기능 오류
- 추천 신뢰 문제
- 루틴 실행 장애
- 온보딩 혼란
- 이탈 신호
- 안전·개인정보 우려
- FAQ 후보
- 제품 개선 요청
- 사용자에게 전달한 안내
- 담당 에이전트
- 후속 조치
- 재발 방지 방법
