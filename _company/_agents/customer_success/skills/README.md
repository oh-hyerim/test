# 🤝 Customer Success 스킬

_베타 사용자 지원·문의 처리·피드백 분석에서 검증된 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 실제 사용자 지원과 베타 운영에서 검증된 안내·분류·에스컬레이션 방법을 저장한다.

## 스킬 추가 원칙

- 실제 사용자 지원에서 검증된 패턴만 추가한다.
- 지원 대상·상황·적용 범위를 함께 기록한다.
- 의료·법률·개인정보 관련 안내는 전문가 검토 여부를 기록한다.
- 사용자의 개인정보·피부 사진·건강정보를 스킬 파일에 저장하지 않는다.
- 단순한 사용자 한 명의 의견을 일반적인 지원 원칙으로 승격하지 않는다.
- 오래된 FAQ와 안내는 현재 제품과 맞는지 다시 확인한다.

## 나중에 추가할 스킬 예시

- `beta_onboarding.md`
- `support_triage.md`
- `safe_skin_related_support.md`
- `bug_escalation.md`
- `faq_management.md`
- `churn_signal.md`

이 README 자체는 Customer Success의 system prompt에 자동 주입되지 않는다.
