# 🧴 Skin & Cosmetic Advisor 스킬

_피부·화장품·성분·논문 자문에서 검증된 방법과 판단 기준을 저장하는 폴더다._

각 `*.md` 파일에는 실제 자료 검토와 제품 자문에서 검증된 패턴을 저장한다.

## 스킬 추가 원칙

- 출처와 적용 범위를 함께 기록한다.
- 하나의 논문이나 사례만으로 일반 원칙을 만들지 않는다.
- 연구 결과와 전문가 판단을 구분한다.
- 확정 지식과 검토 중인 가설을 구분한다.
- 오래된 자료는 최신 자료와 다시 비교한다.
- 의료적 판단이 필요한 내용은 외부 전문가 검토 여부를 기록한다.
- 사용자 개인정보·피부 사진·비공개 자료를 스킬 파일에 저장하지 않는다.

## 나중에 추가할 스킬 예시

- `literature_review.md`
- `paper_quality_assessment.md`
- `ingredient_evidence.md`
- `skin_concern_framework.md`
- `routine_safety.md`
- `recommendation_evidence.md`
- `knowledge_update_policy.md`
- `medical_boundary.md`
