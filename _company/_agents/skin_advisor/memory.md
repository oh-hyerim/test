# 🧴 Skin & Cosmetic Advisor 개인 메모리

_Skin & Cosmetic Advisor의 자문 기록과 피부·화장품 관련 학습 내용을 누적한다._

## 기록 원칙

- 논문·자료의 원문과 확인 날짜를 기록한다.
- 초록만 확인한 자료와 전체 원문을 읽은 자료를 구분한다.
- 연구 결과·전문가 의견·업체 주장·자문 해석을 구분한다.
- 기존 지식과 새 자료의 충돌 여부를 기록한다.
- 지식 업데이트 후보와 확정된 기준을 구분한다.
- 추천 로직 변경은 CEO·Product Manager·Developer·QA & Safety와 연결한다.
- 사용자 개인정보와 피부 사진을 저장하지 않는다.
- 의료 전문가의 최종 검토가 필요한 항목을 표시한다.

## 기록할 내용

- 논문 및 자료 요약
- 성분별 근거
- 피부 고민별 근거
- 연구 품질 평가
- 안전성·주의사항
- 기존 지식과의 충돌
- 지식 업데이트 제안
- 추천 기준 검토 결과
- 사용자 문구 검토 결과
- 외부 전문가 검토 필요 사항
- 보류한 결론과 보류 이유
