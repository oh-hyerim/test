# 🤖 AI & Recommendation Specialist 스킬

_AI 분석·추천 기능의 설계·평가·안전 검토에서 검증된 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 실제 AI 기능 평가와 추천 기준 검토에서 검증된 방법을 저장한다.

## 스킬 추가 원칙

- 실제 평가·테스트·운영 검토에서 검증된 패턴만 추가한다.
- 모델·프롬프트·추천 기준의 버전을 기록한다.
- 적용 조건과 한계를 함께 기록한다.
- 테스트하지 않은 성능을 검증된 기준처럼 저장하지 않는다.
- 의료·피부·안전 관련 판단은 전문가 검토 여부를 기록한다.
- 실제 사용자 데이터·피부 사진·개인정보를 저장하지 않는다.
- 오래된 평가 방식은 현재 모델과 제품에 맞는지 다시 확인한다.
