# 🛡️ QA & Safety 스킬

_제품 품질·보안·개인정보·피부 안전·출시 검수에서 검증된 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 실제 테스트·검수·출시 준비 과정에서 검증된 체크리스트와 판단 방법을 저장한다.

## 스킬 추가 원칙

- 실제 검수에서 사용하고 검증된 패턴만 추가한다.
- 검수 범위와 적용 조건을 함께 기록한다.
- 테스트 결과와 추정 결과를 구분한다.
- 특정 환경에만 적용되는 기준은 적용 범위를 명시한다.
- 의료·법률·보안 기준은 최신성을 다시 확인한다.
- 개인정보·피부 사진·건강정보를 스킬 파일에 저장하지 않는다.

## 나중에 추가할 스킬 예시

- `acceptance_testing.md`
- `privacy_audit.md`
- `security_review.md`
- `recommendation_safety.md`
- `accessibility_testing.md`
- `release_checklist.md`
- `bug_severity.md`
- `regression_testing.md`

이 README 자체는 QA & Safety의 system prompt에 자동 주입되지 않는다.
