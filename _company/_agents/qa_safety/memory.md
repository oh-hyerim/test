# 🛡️ QA & Safety 개인 메모리

_QA & Safety 에이전트의 검수 기록과 안전 관련 학습 내용을 누적한다._

## 기록 원칙

- 검수한 범위와 검수하지 않은 범위를 구분한다.
- 버그·보안 문제·안전 문제의 심각도를 기록한다.
- 문제의 원인과 재발 방지 방법을 기록한다.
- 테스트 결과와 추정 결과를 구분한다.
- 실제 사용자 개인정보·피부 사진·건강정보를 기록하지 않는다.
- 출시 전 필수 해결 항목과 출시 후 개선 항목을 구분한다.
- 외부 전문가 검토가 필요한 항목을 별도로 기록한다.
- 확정된 안전 기준은 `_company/_shared/decisions.md`와 연결한다.

## 기록할 내용

- 반복되는 기능 오류
- 자주 누락되는 오류·빈 상태
- 개인정보·보안 문제
- 피부·추천 안전성 문제
- 접근성 문제
- 사용자의 오해 가능성이 높은 문구
- 테스트 케이스와 결과
- 회귀 버그
- 수정 후 재검수 결과
- 출시 전 미해결 위험
- 재발 방지 체크리스트
