# 📈 Growth 개인 메모리

_Growth 에이전트의 채널·실험·사용자 획득·출시 관련 학습 내용을 누적한다._

## 기록 원칙

- 실제 실행한 실험과 계획만 있는 실험을 구분한다.
- 노출·유입·가입·활성화·재방문을 구분한다.
- 채널별 성과와 제품 자체의 문제를 구분한다.
- 비용·기간·대상 사용자·측정 방법을 기록한다.
- 개인정보와 피부·건강정보를 저장하지 않는다.
- 성공한 실험뿐 아니라 실패한 실험과 보류 이유도 기록한다.
- 확정된 성장 결정은 `_company/_shared/decisions.md`와 연결한다.

## 기록할 내용

- 핵심 고객이 활동하는 채널
- 채널별 성장 가설
- 베타 사용자 모집 결과
- 앱스토어 출시 준비 결과
- 콘텐츠·광고·제휴 실험
- 유입·가입·활성화·재방문 지표
- 채널별 비용과 운영 부담
- 실패한 성장 가설
- 사용자 추천·공유 행동
- 개인정보·광고·제휴 검토 사항
- 다음에 재검토할 채널
