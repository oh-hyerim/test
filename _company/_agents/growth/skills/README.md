# 📈 Growth 스킬

_사용자 획득·앱 출시·성장 실험에서 검증된 방법과 반복 가능한 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 실제 성장 실험·베타테스트·출시 준비·채널 분석에서 검증된 패턴을 저장한다.

## 스킬 추가 원칙

- 실제 실행과 결과가 확인된 패턴만 추가한다.
- 계획·가설·추정은 검증된 스킬과 구분한다.
- 적용 채널·고객군·제품 단계·한계를 기록한다.
- 조회수나 팔로워만으로 성공한 패턴을 판단하지 않는다.
- 광고·제휴·개인정보 관련 조건을 함께 기록한다.
- 오래된 채널 전략은 현재 사용자 행동과 맞는지 다시 확인한다.
