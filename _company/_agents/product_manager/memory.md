# 📋 Product Manager 개인 메모리

_Product Manager 에이전트의 업무 기록과 제품 기획 학습 내용을 누적한다._

## 기록 원칙

- 확정된 제품 결정은 `_company/_shared/decisions.md`에도 기록한다.
- 검증되지 않은 아이디어와 확정된 요구사항을 구분한다.
- 오래된 요구사항이 현재 MVP 범위에 포함되는지 다시 확인한다.
- 제품 가설과 검증 결과를 연결한다.
- 사용자의 직접 지시와 에이전트의 제안을 구분한다.

## 기록할 내용

- 핵심 고객과 고객 문제
- 제품 가설
- MVP 포함·제외 결정
- 기능 우선순위 변경
- 사용자 테스트 결과
- 반복되는 요구사항
- 실패한 가설
- 기능 간 의존성
- 개발·디자인 제약
- 안전·개인정보 관련 결정
- 다음에 재검토할 조건
