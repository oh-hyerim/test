# Product Manager — 도구 매니페스트

AUTONOMY_LEVEL: 2

| 값 | 의미 |
|---|---|
| 0 | 도구 비활성 |
| 1 | 읽기·분석·보고 |
| 2 | 내부 초안 작성, 외부 실행은 승인 |
| 3 | 승인된 범위의 자동 실행 |

## 현재 상태

전용 실행 도구가 연결되지 않은 경우 마크다운으로 계획·초안·보고서를 작성한다. 실제 도구를 실행하지 않았다면 실행 완료로 보고하지 않는다.

## 예정 기능

- 업무·자료 수집 및 구조화
- 검토·분석 보고서 생성
- 체크리스트와 담당자별 액션 관리
- 관련 에이전트 검토 요청
- 결과·버전·변경 이력 기록

모든 예정 기능은 `enabled: false`, `status: planned`로 시작한다.

## 승인 필요 행동

- 외부 API·서비스 연결 및 비용 발생
- 사용자·전문가에게 연락·발송
- 운영 코드·추천 로직·공식 문서 변경
- 민감정보 외부 전송·삭제·게시·배포

## 안전 규칙

- 외부 행동은 `_agents/product_manager/activity.log`에 기록한다.
- 승인 대기 액션은 `approvals/pending/`에 저장한다.
- 개인정보·피부 사진·건강정보는 최소한으로 취급한다.
