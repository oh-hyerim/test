# 📋 Product Manager 스킬

_재사용 가능한 제품 기획 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 Product Manager가 검증한 제품 기획 방법, 요구사항 작성 방식, 우선순위 판단 기준, 사용자 테스트 패턴을 저장한다.

## 스킬 추가 원칙

- 실제 업무에서 검증된 패턴만 추가한다.
- 단순한 아이디어나 일회성 제안은 바로 스킬로 승격하지 않는다.
- 스킬에는 적용 조건과 한계를 함께 기록한다.
- 오래된 스킬은 현재 제품 목표와 맞는지 다시 확인한다.
- 사용자 결정과 에이전트의 제안을 구분한다.

## 나중에 추가할 스킬 예시

- `mvp_scoping.md`
- `requirements_writing.md`
- `user_story_design.md`
- `hypothesis_validation.md`
- `acceptance_criteria.md`
- `prioritization_framework.md`
- `user_testing.md`
- `product_decision_record.md`

이 README 자체는 Product Manager의 system prompt에 자동 주입되지 않는다.
