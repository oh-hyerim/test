# 🧑‍🤝‍🧑 Customer Research 스킬

_검증된 고객 조사 방법과 반복적으로 사용할 수 있는 조사 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 실제 조사에서 검증된 인터뷰·설문·사용성 테스트·고객 문제 분석 방법을 저장한다.

## 스킬 추가 원칙

- 실제 고객 조사나 테스트에서 검증된 패턴만 추가한다.
- 조사자의 개인적인 추측을 검증된 패턴처럼 저장하지 않는다.
- 적용 대상과 한계를 함께 기록한다.
- 특정 고객 한 명의 의견을 일반 원칙으로 승격하지 않는다.
- 개인정보와 원본 인터뷰 자료를 스킬 파일에 저장하지 않는다.
- 오래된 조사 방법이 현재 제품 목표에 맞는지 다시 확인한다.

## 나중에 추가할 스킬 예시

- `customer_interview.md`
- `non_leading_questions.md`
- `problem_validation.md`
- `usability_testing.md`
- `feedback_coding.md`
- `willingness_to_pay.md`
- `customer_segment_analysis.md`
- `research_ethics.md`

이 README 자체는 Customer Research의 system prompt에 자동 주입되지 않는다.
