# 🗃️ Knowledge Curator 개인 메모리

_Knowledge Curator의 지식 항목·출처·업데이트·충돌 관리 기록을 누적한다._

## 기록 원칙

- 모든 지식 항목에 출처와 확인 날짜를 연결한다.
- 공식 지식·참고자료·검토 중인 자료를 구분한다.
- 새 자료와 기존 지식의 관계를 기록한다.
- 승인된 변경과 제안된 변경을 구분한다.
- 변경 전·후 내용을 추적할 수 있게 한다.
- 오래된 자료와 재검토 조건을 기록한다.
- 개인정보·피부 사진·건강정보를 저장하지 않는다.

## 기록할 내용

- 지식 항목
- 출처와 원문
- 근거 수준
- 신뢰도
- 기존 지식과의 관계
- 충돌 자료
- 업데이트 후보
- 검토 상태
- 승인·보류·반려 결정
- 제품 영향
- 추천 로직 영향
- 사용자 문구 영향
- 재검토 날짜와 조건
