# 🗃️ Knowledge Curator 스킬

_지식베이스·근거·출처·업데이트 관리에서 검증된 패턴을 저장하는 폴더다._

각 `*.md` 파일에는 자료 비교·출처 관리·충돌 분류·지식 업데이트·변경 이력 관리에 사용한 검증된 방법을 저장한다.

## 스킬 추가 원칙

- 실제 지식 관리 업무에서 검증된 패턴만 추가한다.
- 자료 유형과 적용 범위를 함께 기록한다.
- 공식 지식과 참고자료를 구분한다.
- 업데이트 승인 조건과 한계를 기록한다.
- 오래된 스킬은 현재 지식 구조에 맞는지 다시 확인한다.
- 논문 원문·개인정보·피부 사진을 스킬 파일에 저장하지 않는다.

## 나중에 추가할 스킬 예시

- `knowledge_item_schema.md`
- `source_registry.md`
- `evidence_comparison.md`
- `conflict_resolution.md`
- `knowledge_versioning.md`
- `staleness_review.md`
- `expert_review_workflow.md`
- `product_impact_mapping.md`

이 README 자체는 Knowledge Curator의 system prompt에 자동 주입되지 않는다.
