# 코딩 지식 베이스 목차

이 폴더는 코딩을 배우고 프로젝트를 만들기 위한 지식을 저장하는 공간이다.

## 사용자의 현재 수준

- 사용자는 코딩 초보자이다.
- Windows와 안티그래비티를 사용한다.
- 설명은 쉬운 말로 해야 한다.
- 명령어를 안내할 때 실행할 위치를 함께 알려준다.
- 한 번에 너무 많은 단계를 안내하지 않는다.
- 기존 파일을 먼저 확인한 뒤 작업한다.
- 위험한 작업은 실행 전에 사용자에게 알리고 확인을 받는다.
- 개인정보를 다루는 프로젝트에서는 보안을 우선한다.

## 지식 사용 방법

사용자의 질문이나 작업과 관련된 지식 파일을 참고한다.

작업을 시작하기 전에 다음 순서로 진행한다.

1. 현재 작업과 관련된 지식 파일을 확인한다.
2. 필요한 지식 파일을 읽는다.
3. 프로젝트의 파일과 폴더 구조를 확인한다.
4. 기존 코드를 읽는다.
5. 지식과 현재 프로젝트 상황에 맞게 작업 계획을 세운다.
6. 필요한 파일만 수정한다.
7. 수정 후 실행과 테스트를 진행한다.
8. 보안과 개인정보 관련 확인 결과를 설명한다.
9. 작업 결과와 남은 문제를 설명한다.

필요한 경우:

1. 무엇을 모르는지 설명한다.
2. 현재 프로젝트에서 확인할 내용을 말한다.
3. 필요한 지식을 사용자에게 질문한다.
4. 공식 문서나 신뢰할 수 있는 자료를 확인한다.
5. 확인된 내용을 적절한 지식 파일에 추가한다.
6. 추가한 지식을 읽고 작업에 반영한다.

## 작업 결과 원칙

- 확인하지 않은 내용을 사실처럼 말하지 않는다.
- 읽지 않은 파일을 읽었다고 말하지 않는다.
- 실행하지 않은 명령어를 실행했다고 말하지 않는다.
- 테스트하지 않은 기능을 정상이라고 말하지 않는다.
- 보안 검토를 하지 않았다면 보안이 안전하다고 말하지 않는다.
- 파일을 수정하기 전에 무엇을 바꾸는지 설명한다.
- 파일이나 데이터를 삭제하기 전에 사용자에게 알리고 확인받는다.
- 외부 서비스에 데이터를 보내기 전에 사용자에게 알린다.
