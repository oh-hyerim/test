# 코딩 지식 베이스 목차

이 폴더는 코딩을 배우고 프로젝트를 만들기 위한 지식을 저장하는 공간이다.

## 사용자의 현재 수준

- 사용자는 코딩 초보자이다.
- Windows와 안티그래비티를 사용한다.
- 설명은 쉬운 말로 해야 한다.
- 명령어를 안내할 때는 실행할 위치를 함께 알려준다.
- 한 번에 너무 많은 단계를 안내하지 않는다.

## 지식 파일 목록

### 01_프로그래밍_기초.md

프로그래밍의 기본 개념을 설명한다.

포함된 내용:

- 프로그래밍의 의미
- 프로그램의 입력, 처리, 출력
- 변수
- 조건문
- 함수
- 오류가 발생했을 때의 기본 확인 방법

### 02_코딩_에이전트_작업규칙.md

AI 코딩 에이전트가 작업할 때 지켜야 하는 규칙이다.

포함된 내용:

- 초보자에게 쉽게 설명하기
- 작업 전 파일 구조 확인하기
- 기존 코드 먼저 읽기
- 필요한 부분만 수정하기
- 오류 발생 시 단계적으로 확인하기
- 위험한 작업 전에 사용자에게 알리기

### 03_터미널과_파일관리.md

터미널 사용법과 파일·폴더 관리 방법을 설명한다.

포함된 내용:

- 현재 위치 확인
- 파일과 폴더 목록 확인
- 폴더 이동
- 파일과 폴더 생성
- 프로그램 실행
- 파일 경로와 명령어 주의사항

### 04_웹개발_기초.md

웹사이트와 웹앱의 기본 구조를 설명한다.

포함된 내용:

- HTML
- CSS
- JavaScript
- 프론트엔드와 백엔드
- 브라우저와 서버
- API
- JSON
- 웹 개발 작업 순서

### 05_Git_기초.md

Git과 GitHub를 이용해 코드와 지식 파일의 변경 내용을 관리하는 방법을 설명한다.

포함된 내용:

- Git과 저장소
- 변경사항 확인
- 커밋
- 원격 저장소
- GitHub에 올리기
- Git 사용 시 주의사항

### 06_디버깅과_오류해결.md

프로그램 오류를 읽고 원인을 찾아 해결하는 방법을 설명한다.

포함된 내용:

- 오류 메시지 읽기
- 문법 오류
- 실행 오류
- 논리 오류
- 오류 해결 순서
- 수정 후 테스트

### 07_데이터베이스_기초.md

데이터를 저장하고 조회하고 수정하고 삭제하는 기본 방법을 설명한다.

포함된 내용:

- 데이터베이스
- 테이블, 행, 열
- 기본 키
- CRUD
- SQL
- SQLite, PostgreSQL, MySQL
- 데이터베이스 작업 시 주의사항

### 08_보안_기초.md

API 키, 비밀번호, 사용자 입력, 인증과 권한 등 프로그램을 안전하게 만드는 기본 원칙을 설명한다.

포함된 내용:

- API 키와 비밀번호 보호
- 환경변수와 `.env` 파일
- 사용자 입력 확인
- SQL 인젝션
- XSS
- 인증과 권한
- 파일 업로드 보안
- 보안 작업 원칙

## 지식 사용 방법

사용자의 질문이나 작업과 관련된 지식 파일이 있으면 해당 파일을 참고한다.

프로그래밍 기초가 필요하면:

01_프로그래밍_기초.md

를 참고한다.

코딩 작업 규칙이 필요하면:

02_코딩_에이전트_작업규칙.md

를 참고한다.

## 지식이 부족할 때

현재 지식 파일에 없는 내용은 추측해서 단정하지 않는다.

필요한 경우:

1. 무엇을 모르는지 설명한다.
2. 필요한 지식을 사용자에게 질문한다.
3. 확인된 내용을 적절한 지식 파일에 추가한다.
