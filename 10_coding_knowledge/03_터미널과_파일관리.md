# 터미널과 파일 관리

## 터미널이란?

터미널은 글자로 컴퓨터에 명령을 내리는 프로그램이다.

마우스로 폴더를 열거나 프로그램을 실행할 수도 있지만, 터미널에 명령어를 입력해서 같은 작업을 할 수도 있다.

## 현재 위치 확인

터미널은 항상 현재 작업 중인 폴더 위치를 기준으로 명령을 실행한다.

Windows PowerShell에서 현재 위치를 확인하는 명령어는 다음과 같다.

```powershell
Get-Location
```

## 폴더 안의 파일 보기

현재 폴더 안에 있는 파일과 폴더를 확인하려면 다음 명령어를 사용한다.

```powershell
Get-ChildItem
```

짧게 다음처럼 사용할 수도 있다.

```powershell
ls
```

## 폴더 이동하기

다른 폴더로 이동하려면 `Set-Location`을 사용한다.

```powershell
Set-Location "폴더 경로"
```

예를 들어 다음과 같이 사용할 수 있다.

```powershell
Set-Location "C:\Users\오혜림\OneDrive\바탕 화면\test"
```

## 상위 폴더로 이동하기

현재 폴더의 한 단계 위로 이동하려면 다음 명령어를 사용한다.

```powershell
cd ..
```

## 새 폴더 만들기

새 폴더를 만들려면 다음 명령어를 사용한다.

```powershell
New-Item -ItemType Directory -Name "폴더이름"
```

## 새 파일 만들기

새 파일을 만들려면 다음 명령어를 사용한다.

```powershell
New-Item -ItemType File -Name "파일이름.md"
```

## 프로그램 실행하기

프로그램 이름이나 명령어를 터미널에 입력하면 프로그램을 실행할 수 있다.

예를 들어 Ollama 모델을 실행하는 명령어는 다음과 같다.

```powershell
ollama run llama3.2:1b
```

## 터미널 명령어를 실행할 때 주의할 점

1. 명령어를 실행하기 전에 현재 폴더 위치를 확인한다.
2. 파일이나 폴더를 삭제하는 명령어는 특히 주의한다.
3. 오류가 나오면 오류 메시지를 지우지 말고 그대로 확인한다.
4. 명령어를 한 번에 여러 개 실행하지 않는다.
5. 무엇을 하는 명령어인지 모르면 실행하기 전에 설명을 요청한다.

## 파일 경로

파일 경로는 파일이 저장된 위치를 뜻한다.

예:

```text
C:\Users\오혜림\OneDrive\바탕 화면\test\10_Coding_Knowledge\03_터미널과_파일관리.md
```

파일 경로에 띄어쓰기가 포함되어 있으면 경로 전체를 큰따옴표로 감싸는 것이 안전하다.

예:

```powershell
Set-Location "C:\Users\오혜림\OneDrive\바탕 화면\test"
```
