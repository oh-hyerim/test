# 코딩 에이전트 작업 규칙

## 사용자의 현재 수준

사용자는 코딩을 처음 배우는 초보자이다.

- 어려운 전문 용어는 쉬운 말로 설명한다.
- 명령어를 알려줄 때 실행할 위치를 함께 알려준다.
- 한 번에 너무 많은 단계를 안내하지 않는다.
- 한 단계가 끝났는지 확인한 뒤 다음 단계로 넘어간다.
- 사용자가 이해했는지 확인하며 진행한다.

## 작업을 시작할 때

코딩 작업을 시작하기 전에 다음 순서로 진행한다.

1. 사용자의 목표를 쉽게 정리한다.
2. 현재 프로젝트의 파일과 폴더 구조를 확인한다.
3. 기존 코드를 먼저 읽는다.
4. 해야 할 일을 작은 단계로 나눈다.
5. 필요한 파일만 수정한다.

## 파일을 수정할 때

- 파일을 읽지 않고 수정하지 않는다.
- 기존 코드를 함부로 삭제하지 않는다.
- 필요한 부분만 수정한다.
- 수정하기 전에 무엇을 바꾸는지 설명한다.
- 비밀번호와 API 키를 코드에 직접 넣지 않는다.

## 오류가 발생했을 때

1. 오류 메시지를 확인한다.
2. 오류가 발생한 파일과 위치를 확인한다.
3. 원인을 추측하지 말고 하나씩 확인한다.
4. 수정한 뒤 다시 실행한다.
5. 해결되었는지 사용자에게 알린다.

## 작업이 끝났을 때

작업이 끝나면 다음 내용을 알려준다.

- 무엇을 변경했는지
- 어떤 명령을 실행했는지
- 테스트가 성공했는지
- 아직 해결되지 않은 문제가 있는지

## 위험한 작업

다음 작업은 실행하기 전에 사용자에게 먼저 알리고 확인한다.

- 파일이나 폴더를 삭제하는 작업
- 데이터를 삭제하는 작업
- 비밀번호나 API 키를 변경하는 작업
- 외부에 파일을 공개하는 작업
- 운영 중인 서비스를 변경하는 작업
