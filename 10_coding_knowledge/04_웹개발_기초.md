# 웹 개발 기초

## 웹사이트란?

웹사이트는 인터넷을 통해 브라우저에서 볼 수 있는 프로그램이다.

웹사이트는 보통 다음 세 가지 기술을 사용한다.

- HTML: 화면의 구조를 만든다.
- CSS: 화면의 모양과 배치를 정한다.
- JavaScript: 화면의 동작과 기능을 만든다.

## HTML

HTML은 웹페이지에 어떤 내용이 있는지 정의한다.

예시:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>나의 웹페이지</title>
  </head>
  <body>
    <h1>안녕하세요</h1>
    <p>첫 번째 웹페이지입니다.</p>
  </body>
</html>
```

주요 HTML 요소:

- `h1`: 큰 제목
- `p`: 문단
- `button`: 버튼
- `img`: 이미지
- `a`: 링크
- `form`: 사용자 입력 양식

## CSS

CSS는 HTML 요소의 색상, 크기, 위치, 간격을 정한다.

예시:

```css
h1 {
  color: blue;
  font-size: 32px;
}
```

CSS에서 자주 사용하는 속성:

- `color`: 글자 색상
- `background-color`: 배경 색상
- `font-size`: 글자 크기
- `margin`: 바깥쪽 여백
- `padding`: 안쪽 여백
- `display`: 요소 배치 방식
- `width`: 너비
- `height`: 높이

## JavaScript

JavaScript는 웹페이지에 동작을 추가한다.

예시:

```javascript
const button = document.querySelector("button");

button.addEventListener("click", () => {
  alert("버튼을 클릭했습니다.");
});
```

위 코드는 버튼을 클릭했을 때 알림창을 보여준다.

## 프론트엔드와 백엔드

### 프론트엔드

사용자의 브라우저에서 실행되는 부분이다.

예:

- 화면
- 버튼
- 메뉴
- 입력창
- 애니메이션

### 백엔드

서버에서 실행되는 부분이다.

예:

- 로그인 처리
- 데이터 저장
- 데이터베이스 연결
- 사용자 권한 확인
- API 제공

## 브라우저와 서버

사용자가 웹페이지를 열면 다음과 같은 과정이 일어난다.

1. 브라우저가 서버에 페이지를 요청한다.
2. 서버가 필요한 파일이나 데이터를 보낸다.
3. 브라우저가 받은 내용을 화면에 표시한다.

## API

API는 프로그램끼리 데이터를 주고받기 위한 약속이다.

예를 들어 웹사이트가 서버에 사용자 정보를 요청하면 서버는 데이터를 응답으로 보낸다.

## JSON

JSON은 데이터를 저장하고 주고받을 때 자주 사용하는 형식이다.

예시:

```json
{
  "name": "혜림",
  "age": 20
}
```

## 웹 개발 작업 순서

웹페이지를 만들 때는 보통 다음 순서로 진행한다.

1. 만들고 싶은 기능을 정리한다.
2. 필요한 화면과 파일을 정한다.
3. HTML로 기본 구조를 만든다.
4. CSS로 화면을 꾸민다.
5. JavaScript로 동작을 추가한다.
6. 브라우저에서 실행해 확인한다.
7. 오류를 수정하고 다시 테스트한다.
