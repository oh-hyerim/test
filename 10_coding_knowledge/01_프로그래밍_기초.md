# 프로그래밍 기초

## 프로그래밍이란?

프로그래밍은 컴퓨터가 해야 할 일을 명령어로 알려주는 것이다.

## 프로그램의 기본 흐름

프로그램은 보통 다음 순서로 작동한다.

1. 입력을 받는다.
2. 입력을 처리한다.
3. 결과를 출력한다.

## 변수란?

변수는 데이터를 저장해두는 이름이다.

예를 들어 사용자의 이름을 저장할 수 있다.

```javascript
const userName = "혜림";
console.log(userName);
```

위 코드에서 `userName`은 사용자의 이름을 저장하는 변수이다.

## 조건문이란?

조건문은 어떤 조건에 따라 다른 작업을 실행할 때 사용한다.

```javascript
const age = 20;

if (age >= 18) {
  console.log("성인입니다.");
} else {
  console.log("미성년자입니다.");
}
```

## 함수란?

함수는 특정 작업을 하나로 묶어 필요할 때 다시 사용하는 것이다.

```javascript
function sayHello() {
  console.log("안녕하세요.");
}

sayHello();
```

## 오류가 발생했을 때

오류가 발생하면 다음 순서로 확인한다.

1. 오류 메시지를 읽는다.
2. 오류가 발생한 파일과 줄을 확인한다.
3. 코드를 한 부분씩 확인한다.
4. 수정한 뒤 다시 실행한다.
