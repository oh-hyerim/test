# Git 기초

## Git이란?

Git은 파일의 변경 기록을 저장하고 관리하는 도구이다.

코드를 수정하다가 문제가 생기면 이전 상태를 확인하거나 되돌릴 수 있다.

## 저장소란?

저장소는 Git이 파일의 변경 기록을 관리하는 프로젝트 폴더이다.

현재 프로젝트 폴더가 Git 저장소인지 확인하려면 터미널에서 다음 명령어를 사용한다.

```powershell
git status
```

## 변경사항 확인

파일을 수정한 뒤 어떤 내용이 변경되었는지 확인하려면 다음 명령어를 사용한다.

```powershell
git diff
```

## 커밋이란?

커밋은 현재 변경된 내용을 하나의 기록으로 저장하는 것이다.

```powershell
git add .
git commit -m "변경 내용 설명"
```

`git add .`는 변경된 파일을 커밋할 준비를 하는 명령어이다.

`git commit`은 준비된 변경사항을 기록으로 저장하는 명령어이다.

## 커밋 메시지

커밋 메시지는 무엇을 변경했는지 알 수 있도록 작성한다.

좋은 예:

```text
웹 개발 기초 지식 추가
```

좋지 않은 예:

```text
수정
```

## 원격 저장소

GitHub에 있는 저장소를 원격 저장소라고 한다.

현재 원격 저장소 주소를 확인하려면 다음 명령어를 사용한다.

```powershell
git remote -v
```

## GitHub에 올리기

변경사항을 GitHub에 올리는 명령어는 다음과 같다.

```powershell
git push
```

## Git 작업 시 주의사항

- 커밋하기 전에 변경된 파일을 확인한다.
- 비밀번호와 API 키를 커밋하지 않는다.
- 삭제할 파일이 있는지 확인한다.
- `git push` 전에 무엇이 공개되는지 확인한다.
- 잘 모르는 Git 명령어는 실행하기 전에 설명을 요청한다.
- 대량 삭제나 강제 되돌리기 명령어는 특히 주의한다.
