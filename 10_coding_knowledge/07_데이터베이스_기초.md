# 데이터베이스 기초

## 데이터베이스란?

데이터베이스는 정보를 저장하고 필요할 때 찾아볼 수 있도록 관리하는 시스템이다.

예를 들어 다음과 같은 정보를 저장할 수 있다.

- 사용자 이름
- 이메일 주소
- 상품 정보
- 주문 내역
- 게시글
- 할 일 목록

## 데이터베이스를 사용하는 이유

프로그램을 종료해도 데이터가 남아 있어야 할 때 데이터베이스를 사용한다.

예를 들어 메모 앱에서 작성한 메모가 프로그램을 닫은 뒤에도 남아 있어야 한다면 메모를 데이터베이스에 저장한다.

## 테이블이란?

테이블은 비슷한 종류의 데이터를 모아두는 공간이다.

예를 들어 사용자를 저장하는 `users` 테이블이 있을 수 있다.

| id | name | email |
|---|---|---|
| 1 | 혜림 | hyerim@example.com |
| 2 | 민수 | minsu@example.com |

## 행과 열

- 행: 데이터 한 개
- 열: 데이터의 종류

위 표에서 한 명의 사용자가 한 행에 해당한다.

## 기본 키

기본 키는 각각의 데이터를 구분하기 위한 고유한 값이다.

보통 `id`라는 이름의 숫자를 기본 키로 사용한다.

```text
id: 1
id: 2
id: 3
```

서로 다른 데이터가 같은 기본 키를 가지면 안 된다.

## CRUD

데이터베이스 작업은 보통 CRUD 네 가지로 나눈다.

- Create: 데이터 생성
- Read: 데이터 조회
- Update: 데이터 수정
- Delete: 데이터 삭제

## SQL이란?

SQL은 데이터베이스에 명령을 내릴 때 사용하는 언어이다.

예를 들어 데이터를 조회할 때 다음과 같은 SQL을 사용할 수 있다.

```sql
SELECT * FROM users;
```

새로운 데이터를 추가하는 예시는 다음과 같다.

```sql
INSERT INTO users (name, email)
VALUES ('혜림', 'hyerim@example.com');
```

데이터를 수정하는 예시는 다음과 같다.

```sql
UPDATE users
SET name = '오혜림'
WHERE id = 1;
```

데이터를 삭제하는 예시는 다음과 같다.

```sql
DELETE FROM users
WHERE id = 1;
```

## 데이터베이스 종류

### SQLite

하나의 파일로 사용할 수 있는 가벼운 데이터베이스이다.

작은 프로젝트나 학습용으로 적합하다.

### PostgreSQL

기능이 많고 안정적인 관계형 데이터베이스이다.

웹서비스와 실제 운영 서비스에서 많이 사용된다.

### MySQL

많이 사용되는 관계형 데이터베이스이다.

웹서비스와 기업 시스템에서 널리 사용된다.

## 데이터베이스 사용 시 주의사항

- 중요한 데이터를 삭제하기 전에 백업한다.
- 사용자의 입력을 그대로 SQL 명령어에 넣지 않는다.
- 비밀번호를 평문으로 저장하지 않는다.
- 실제 운영 데이터베이스에서 테스트하지 않는다.
- 데이터를 수정하거나 삭제하기 전에 대상 데이터를 확인한다.
- 데이터베이스 연결 정보를 코드에 직접 작성하지 않는다.
- 데이터베이스 오류가 발생하면 오류 메시지를 그대로 확인한다.

## 코딩 에이전트의 데이터베이스 작업 원칙

코딩 에이전트는 다음 작업을 하기 전에 사용자에게 설명한다.

- 테이블 삭제
- 데이터 전체 삭제
- 여러 데이터의 일괄 수정
- 데이터베이스 구조 변경
- 운영 데이터베이스 연결
- 백업되지 않은 데이터의 변경

데이터를 삭제하거나 크게 변경하는 명령어는 사용자의 확인 없이 실행하지 않는다.
